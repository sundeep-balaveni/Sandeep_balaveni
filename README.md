## ⚙️ What I Work With  

☁️ I work with AWS and GCP to design and manage scalable cloud infrastructure.  

🐳 I use Docker to build optimized images using multi-stage builds, manage container lifecycle, and push images to remote registries like Docker Hub and AWS ECR.  

☸️ I work with Kubernetes to deploy applications, manage scaling, configure services, and ensure high availability using probes and resource limits.  

📦 I use Terraform as Infrastructure as Code (IaC) to provision and manage cloud resources in a repeatable and automated way.  

🔄 I build CI/CD pipelines using GitHub Actions and Jenkins to automate build, test, and deployment workflows.  

📊 I use monitoring tools like Prometheus and Grafana to observe system performance and ensure reliability in production environments.
